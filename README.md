# 🎮 Автоматический сборщик бесплатных игр

Бот для автоматического сбора бесплатных раздач игр с Epic Games Store, Steam, GOG и других платформ.

## 📋 Возможности

- ✅ Автоматический поиск бесплатных игр на Epic Games, Steam и GOG
- 🤖 Автоматическое добавление игр в библиотеку через Selenium
- 🔐 Безопасное хранение паролей (шифрование)
- 📅 Работа по расписанию
- 🔔 Уведомления о новых играх
- 📊 Прогресс-бар и детальная статистика
- 🎨 Красивый консольный интерфейс с цветами
- 🌐 Поддержка Chrome, Firefox, Edge

## 🚀 Установка

### Требования

- Python 3.8 или новее
- Google Chrome / Firefox / Microsoft Edge (любой на выбор)

### Шаги установки

1. **Скачайте проект**

2. **Создайте виртуальное окружение (рекомендуется)**

```bash
python -m venv venv
```

Активация на Windows:
```bash
venv\Scripts\activate
```

Активация на Linux/Mac:
```bash
source venv/bin/activate
```

3. **Установите зависимости**

```bash
pip install -r requirements.txt
```

4. **Скопируйте пример конфигурации**

```bash
copy config.json.example config.json
```

На Linux/Mac:
```bash
cp config.json.example config.json
```

## ⚙️ Настройка

Откройте файл `config.json` в текстовом редакторе и заполните необходимые данные:

### 1. Настройка платформ

#### Epic Games Store
```json
"epic_games": {
    "enabled": true,
    "email": "ваш_email@example.com",
    "password": "ваш_пароль"
}
```

- `enabled` - включить/выключить платформу (true/false)
- `email` - ваша почта для входа в Epic Games
- `password` - пароль (будет зашифрован автоматически при первом запуске)

#### Steam
```json
"steam": {
    "enabled": true,
    "username": "ваш_логин",
    "password": "ваш_пароль"
}
```

- `enabled` - включить/выключить платформу
- `username` - имя пользователя Steam
- `password` - пароль Steam

⚠️ **Важно**: Если у вас включена двухфакторная аутентификация (Steam Guard), бот попросит ввести код при первом запуске. Для полностью автоматической работы рекомендуется временно отключить 2FA или настроить доверенное устройство.

#### GOG
```json
"gog": {
    "enabled": true,
    "email": "ваш_email@example.com",
    "password": "ваш_пароль"
}
```

- `enabled` - включить/выключить платформу
- `email` - почта GOG
- `password` - пароль GOG

### 2. Общие настройки

```json
"settings": {
    "headless": false,
    "schedule_time": "10:00",
    "notifications": true,
    "browser": "chrome"
}
```

#### Параметры:

- **headless** (true/false)
  - `false` - браузер будет виден (рекомендуется для первого запуска)
  - `true` - браузер работает в фоновом режиме (быстрее, но не видно процесса)

- **schedule_time** (формат "ЧЧ:ММ")
  - Время ежедневного запуска проверки
  - Примеры: "10:00", "15:30", "23:00"
  - Оставьте пустым ("") чтобы отключить расписание

- **notifications** (true/false)
  - `true` - показывать системные уведомления о новых играх
  - `false` - отключить уведомления

- **browser** ("chrome", "firefox", "edge")
  - Выберите браузер для работы
  - Браузер должен быть установлен в системе
  - Драйверы скачиваются автоматически

## 🎯 Использование

### Однократный запуск

Запустить проверку один раз прямо сейчас:

```bash
python main.py
```

### Запуск по расписанию

Запустить бота в режиме ожидания - он будет автоматически проверять игры каждый день в указанное время:

```bash
python main.py --schedule
```

Бот будет работать в фоне. Для остановки нажмите `Ctrl+C`.

### Автозапуск при загрузке системы

#### Windows (через планировщик задач):

1. Откройте "Планировщик заданий" (Task Scheduler)
2. Создайте новую задачу
3. Триггер: При запуске системы
4. Действие: Запустить программу
5. Программа: `C:\путь\к\python.exe`
6. Аргументы: `C:\путь\к\main.py --schedule`

#### Linux (через systemd или cron):

Добавьте в crontab:
```bash
@reboot cd /путь/к/проекту && /путь/к/python main.py --schedule
```

## 🔒 Безопасность

### Шифрование паролей

- При первом запуске все пароли из `config.json` автоматически шифруются
- Создается файл `.encryption_key` с ключом шифрования
- Пароли в конфиге заменяются на зашифрованные версии

⚠️ **Важно**:
- Не удаляйте файл `.encryption_key` - без него расшифровка паролей невозможна
- Не публикуйте файл `config.json` и `.encryption_key`
- Не храните эти файлы в публичных репозиториях

### Рекомендации

- Используйте отдельные пароли только для этих сервисов
- Регулярно меняйте пароли
- Включите двухфакторную аутентификацию где возможно (но учтите ограничения автоматизации)

## 🛠️ Решение проблем

### Браузер не запускается

**Проблема**: Ошибка при запуске ChromeDriver/GeckoDriver

**Решение**:
- Убедитесь, что браузер установлен
- Проверьте подключение к интернету (драйверы скачиваются автоматически)
- Попробуйте другой браузер в настройках `config.json`

### Не удается войти в аккаунт

**Проблема**: Бот не может авторизоваться

**Решение**:
- Проверьте правильность логина и пароля
- Отключите двухфакторную аутентификацию
- Убедитесь, что аккаунт не заблокирован
- Попробуйте войти вручную через браузер
- Установите `"headless": false` чтобы видеть процесс входа

### Игры не добавляются

**Проблема**: Бот находит игры, но не добавляет их

**Возможные причины**:
- Игры уже есть в вашей библиотеке
- Изменился интерфейс сайта (требуется обновление селекторов)
- Требуется капча или дополнительная проверка
- Слишком быстрое выполнение (попробуйте увеличить задержки)

**Решение**:
- Установите `"headless": false` для наблюдения за процессом
- Проверьте вручную доступность игр на сайте
- Обновите приложение до последней версии

### Уведомления не работают

**Проблема**: Не приходят системные уведомления

**Решение**:
- Проверьте настройку `"notifications": true` в конфиге
- Убедитесь, что уведомления разрешены в системе
- На Linux может потребоваться установка `libnotify`

## 🔧 Технические детали

### Используемые библиотеки

- **selenium** - автоматизация браузера
- **webdriver-manager** - автоматическая установка драйверов
- **cryptography** - шифрование паролей
- **schedule** - планировщик задач
- **tqdm** - прогресс-бары
- **colorama** - цветной вывод в консоли
- **plyer** - системные уведомления
- **requests** - HTTP запросы

### Как работает шифрование

1. При первом запуске генерируется ключ Fernet (симметричное шифрование)
2. Ключ сохраняется в `.encryption_key`
3. Все пароли из конфига шифруются этим ключом
4. При каждом запуске пароли расшифровываются для использования
5. В конфиге хранятся только зашифрованные версии

### Selenium и обход детектирования

Приложение использует несколько техник для обхода детектирования автоматизации:
- Удаление флага `navigator.webdriver`
- Использование реального User-Agent
- Отключение флагов автоматизации
- Естественные задержки между действиями

## ⚠️ Важные замечания

1. **Легальность**: Использование автоматизации может нарушать условия использования некоторых платформ. Используйте на свой риск.

2. **Обновления сайтов**: Сайты магазинов могут обновлять свой интерфейс, что может сломать работу бота. В таких случаях требуется обновление селекторов в коде.

3. **Капча**: Некоторые платформы могут показывать капчу при подозрении на автоматизацию. В таких случаях потребуется ручное вмешательство.

4. **Двухфакторная аутентификация**: Полная автоматизация невозможна при активной 2FA. Потребуется ручной ввод кода.

5. **Производительность**: Для экономии ресурсов используйте режим `"headless": true` после проверки работоспособности.
